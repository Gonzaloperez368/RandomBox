# RandomBox

Una caja de herramientas web para elegir al azar, organizar grupos y tomar decisiones: generador de números, selector de nombres/palabras (con ruleta), generador de grupos, lanzamiento de moneda, mezclador y torneos.

**Estado actual:** en desarrollo — FASE 1 (estructura básica).

## Cómo probarlo

No hace falta instalar nada. Abrí `index.html` directamente en el navegador (doble clic, o `start index.html` desde PowerShell).

## Stack

HTML5, CSS3 y JavaScript vanilla. Sin frameworks ni dependencias externas.
